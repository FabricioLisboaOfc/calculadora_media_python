# Calculadora de Média do Aluno

> Um programa em Python que calcula a média de duas notas e informa se o aluno foi aprovado ou reprovado.

## 💻 Sobre o Projeto

Este projeto foi desenvolvido para criar uma calculadora simples de média de notas utilizando a linguagem **Python**.

O programa solicita ao usuário duas notas, realiza o cálculo da média aritmética e apresenta o resultado final.

Após calcular a média, o sistema verifica o desempenho do aluno. Caso a média seja maior ou igual a **7,0**, o aluno é considerado **APROVADO**. Caso seja menor que **7,0**, o aluno é considerado **REPROVADO**.

O projeto foi desenvolvido como atividade acadêmica da disciplina de **Designer Profissional**, com o objetivo de praticar conceitos de programação, organização de código e documentação de projetos.

## ✨ Funcionalidades

* Solicitação da primeira nota do aluno
* Solicitação da segunda nota do aluno
* Cálculo automático da média
* Exibição da média final com duas casas decimais
* Verificação do status do aluno
* Exibição da mensagem de **APROVADO** ou **REPROVADO**

## 🛠️ Tecnologias Utilizadas

## 🚀 Como Executar o Projeto

### Pré-requisitos

Você precisa ter o **Python 3** instalado na sua máquina.

Também é recomendado utilizar o [Visual Studio Code](https://code.visualstudio.com/) para visualizar e executar o projeto.


### Exemplo de execução

```text
=== Sistema de Notas do Aluno ===

Digite a primeira nota: 8
Digite a segunda nota: 7

A média final é: 7.50
Status: APROVADO!
```
